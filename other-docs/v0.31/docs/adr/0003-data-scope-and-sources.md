# ADR-0003 数据范围与来源
状态：accepted　｜　日期：2026-11-10　｜　决策人：产品负责人

## 背景
单招由各校单独命题、单独组织考试，没有统一排名，历史数据只有辅助作用。更早年份的录取数据没有参考价值，补录成本高。

## 决策
1. 只用官方来源：省教育考试院、各校官网与招办公告、报名系统公布的聚合人数。不使用第三方汇总，不抓登录后内容，不采集考生个人信息。
2. 院校名单：用已有的 2024–2026 年名单；2027 年官方名单公布后校准。
3. 简章：2024–2026 已采集；2027 年按简章流水线监控、抽取、审核、发布。
4. 录取数据：只有 2026 年；缺失标“未公布”；**不再补 2026 年以前的数据**，不提供多年趋势。
5. 报名人数：“第一志愿第一专业”口径，按公布日快照（T+1）；竞争度分母缺失返回 null，必须标注参考计划数口径。
6. 每条事实数据带 `source_url`、`source_type`、`fetched_at`、`verified_status`（draft / checked / published）；模型抽取结果先为 draft，经校验与抽检后才能 published。

## 后果
- 数据模型去掉多年趋势相关字段与页面；Demo 与 Mock 也不得出现 2026 年以前的录取数据。
- 院校名单需要“各年是否在名单内”的标记，用于处理退出、新增、更名。
- 2026 年每日报名数据是否可得，决定“与去年同期对比”和回放演练的形式（Q17）。
